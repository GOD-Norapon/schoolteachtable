# ระบบจัดตารางสอนออนไลน์ (Next.js + Supabase + Vercel)

เว็บแอปพลิเคชันจัดตารางสอนโรงเรียนออนไลน์ รองรับการทำงานร่วมกันของครูแต่ละกลุ่มสาระ การตรวจนับยอดคาบรายห้องเรียนให้ครบพอดีก่อนจัดตาราง ระบบจัดตารางสอนอัตโนมัติครบทั้ง **21 เงื่อนไข** โหมดนั่งดูและปรับแก้ไขรายกรณีแบบหน้าจอคู่ (Split-View) การพิมพ์ตารางสอนรายคนพร้อมสรุปจำนวนคาบลงกระดาษ A4 แนวนอน และการส่งออกไฟล์ Excel (`.xlsx`)

---

## ขั้นตอนการใช้งานจริง 4 ขั้นตอน
1. **ครูและตัวแทนกลุ่มสาระช่วยกันลงข้อมูลพื้นฐาน**
   - ตั้งค่าเวลาเรียน จำนวนคาบ พักเบรกเช้า 20 นาที (หลังคาบ 2) พักกลางวัน และกฎช่วงบ่าย/คาบ 8 (`/time-structure`)
   - ตั้งค่ากลุ่มสาระ (ยกเว้นบ่าย 3 คาบติด / ยกเว้นเพดานคาบ 8 รายกลุ่มสาระ) และล็อคคาบประชุมฝ่าย (`/departments`)
   - กำหนดห้องเรียน คาบอิสระรายห้อง (แต่ละห้องมีไม่เท่ากันได้) ครูที่ปรึกษา และห้องแล็บ/ห้องพิเศษที่ใช้ร่วมกัน (`/classrooms`)
   - กำหนดครูผู้สอนและล็อคคาบไม่สอนรายคน เช่น คาบแรกของทุกวัน (`/teachers`)
   - กำหนดรายวิชาและเงื่อนไขพิเศษ เช่น ให้วิชาพละเรียนคาบ 4 หรือ 8 และเรียนศิลปะก่อนพละ (`/subjects`)
   - ครูแต่ละกลุ่มสาระช่วยกันคีย์แผนการสอนรายห้อง (รองรับสอนร่วม >1 คน, ระบุห้องแล็บร่วม หรือเว้นว่างเพื่อใช้ห้องนักเรียน, นำเข้าจากไฟล์ Excel ได้) (`/assignments`)
   - กำหนดคาบล็อคทั้งโรงเรียน (ชุมนุม), คาบร่วมระดับชั้น (ลูกเสือ ม.1–3), อบรมคุณธรรม & Homeroom (ผูกครูที่ปรึกษาอัตโนมัติ), วิชาเลือกเสรีพร้อมกันบางห้อง (เช่น ม.2 ห้อง 7–10), และล็อควิชานักเรียน (เช่น นศท. ศุกร์ คาบ 6–8) (`/special-blocks`)
2. **ตรวจสอบยอดคาบแต่ละห้องให้ครบพอดีก่อนจัดตาราง (`/`)**
   - หน้า Dashboard แสดงตาราง Matrix ตรวจนับยอดคาบของทุกห้องเรียนเทียบกับจำนวนคาบเต็มต่อสัปดาห์ (เช่น `40/40` คาบ) พร้อมตรวจเช็คภาระงานครูและห้องปฏิบัติการร่วม
3. **กดจัดตารางสอนอัตโนมัติ & นั่งดูปรับแก้ไขรายกรณี (`/scheduler`)**
   - ประมวลผลผ่าน Web Worker บนเบราว์เซอร์ (ไม่ติด Timeout ของ Vercel)
   - เปิดดูตารางเทียบ **2 หน้าจอคู่กัน (ห้องเรียน ⇄ ครูผู้สอน)** ลากวางหรือคลิกสลับคาบพร้อมสีไฮไลต์ (เขียว/เหลือง/ส้ม/แดง) ตัวช่วยหาคู่สลับอัตโนมัติ (Smart Swap Finder) ปักหมุดคาบ (`📌`) และโหมด **อนุโลมรายกรณี** พร้อมบันทึกหมายเหตุ
4. **พิมพ์ตารางสอนรายคนพร้อมสรุปจำนวนคาบ & ส่งออก Excel (`/reports`)**
   - พิมพ์ตารางสอนรายครู 1 หน้า A4 แนวนอนต่อ 1 ท่าน พร้อมตารางสรุปรายวิชาและยอดคาบแยกประเภทในแผ่นเดียว
   - พิมพ์ตารางเรียนรายห้อง ตารางการใช้ห้องปฏิบัติการ ใบสรุปภาระงานครูทั้งโรงเรียน และดาวน์โหลดไฟล์ `.xlsx` ครบ 4 แผ่นงาน

## การเชื่อมต่อ Supabase ออนไลน์
1. เปิด **Supabase Dashboard → SQL Editor** แล้วรันสคริปต์ในไฟล์ `supabase/migrations/001_initial_schema.sql` (หรือกดปุ่ม **"คัดลอก SQL Schema"** จากหน้าต่างตั้งค่า Supabase มุมขวาบนของเว็บ)
2. นำ **Project URL** (`https://<project-ref>.supabase.co`) มาใส่ใน `.env.local` หรือวางในหน้าต่าง **"ตั้งค่าเชื่อม Supabase ออนไลน์"** บนหน้าเว็บได้ทันที:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project-id.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_5LdJGRJiShjri_JAUy0duw_PzWvZH6g
   ```

## คำสั่งรันในเครื่อง & การนำขึ้น Vercel
```bash
# รันโหมดพัฒนาในเครื่อง (http://localhost:3000)
npm run dev

# รันชุดทดสอบอัตโนมัติตรวจสอบเงื่อนไข Solver ทั้ง 21 ข้อ
npm test

# ทดสอบ Build สำหรับ Production
npm run build
```

### นำขึ้นออนไลน์ผ่าน Vercel
1. อัปโหลดโปรเจกต์ขึ้น GitHub / GitLab หรือใช้คำสั่ง `npx vercel`
2. ตั้งค่า Environment Variables ในหน้าโปรเจกต์บน Vercel:
   - `NEXT_PUBLIC_SUPABASE_URL` = URL โปรเจกต์ Supabase ของโรงเรียน
   - `NEXT_PUBLIC_SUPABASE_ANON_KEY` = `sb_publishable_5LdJGRJiShjri_JAUy0duw_PzWvZH6g`
3. กด **Deploy** พร้อมใช้งานออนไลน์ร่วมกันได้ทันที
